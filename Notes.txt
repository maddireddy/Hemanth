Project Notes - efg-platform-list
================================

This document captures step-by-step instructions for: required software installs, classpath / JAVA_HOME / environment configuration, building the project, running the application (producer + consumer), debugging, and end-to-end testing. Tailored for macOS (zsh) and the current project layout.

1) Prerequisites (software to install)
-------------------------------------
- Java 8 (JDK 1.8) — required for building this project (sourceCompatibility = 1.8).
  - Install using Homebrew (Temurin/CORRETTO) or your JDK manager:

    ```bash
    brew tap homebrew/cask-versions
    brew install --cask temurin8    # or corretto8, adoptopenjdk8, etc.
    ```

- Kafka & Zookeeper
  - Install and run via Homebrew (quick for local dev):

    ```bash
    brew install kafka        # if not installed
    brew services start zookeeper
    brew services start kafka
    ```

  - Alternatively run Kafka + Schema Registry via docker-compose if you prefer containers.

- (Optional) Confluent Schema Registry — if you plan to use Confluent Avro serializers
  - Run via Docker Compose or install Confluent Platform locally.

- kcat (formerly kafkacat) — nice CLI consumer/producer
  ```bash
  brew install kcat
  ```

- jq — helpful to pretty-print JSON in shell
  ```bash
  brew install jq
  ```

2) Environment configuration (JAVA_HOME and PATH)
-------------------------------------------------
- The build and some Gradle/Groovy compiled script classes expect to run under Java 8. Confirm current java:

  ```bash
  java -version
  echo $JAVA_HOME
  /usr/libexec/java_home -V
  ```

- To set Java 8 for the current shell session:

  ```bash
  export JAVA_HOME=$(/usr/libexec/java_home -v 1.8)
  export PATH="$JAVA_HOME/bin:$PATH"
  java -version    # should report 1.8.x
  ```

- To make this persistent add the export lines to `~/.zshrc`.

3) Build the project (Gradle helper)
-----------------------------------
- This repository includes a helper script `gradle7.sh` that downloads/uses Gradle 7.6 to avoid system Gradle issues.

  ```bash
  chmod +x ./gradle7.sh
  ./gradle7.sh clean bootJar --no-daemon
  ```

- Output: `build/libs/efg-platform-list-0.0.1-SNAPSHOT.jar` (or similar).
